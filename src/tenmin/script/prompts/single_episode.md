## 高能点清单

下面是从字幕轨机械分析出来的信号，**不是**语义判断，是给你的探测器读数：

- `gap:Ns` = 连续 N 秒没有任何台词。动画的演出语法是「该炫的时候不说话」，所以长间隙几乎等于视觉高光（打斗、定格、大场面、无声的情绪爆发）。**这些区间是纯字幕方案取不到的画面，必须优先用。**
- `density:X` = 该行的字/秒。数值远低于全集中位数意味着一句话被拖得很长——尖叫、哽住、颤声、拖腔，都是情绪爆发点。
- `shift:z=±X` = 30 秒窗口内台词密度的突变，通常对应场景切换或节奏换挡。

## 对白轨

格式为 `行号 | 起 - 止 | 说话人 | 类型 | 文本`。类型 `monologue` 是内心独白（不是说出口的话，别写成对话）。带 `?` 标记的行是疑似 OCR 噪声（车牌、招牌、屏幕文字混进了字幕），**内容可疑，不要引用，也不要当成台词写进旁白**。

## 交付要求

### 节点结构

- 第一个节点固定 `label = "Hook 开场"`，`role = "hook"`。用本集最抓人的画面或最炸的一句话开场，禁止「本片讲述了」这种总结腔。
- 中间节点 `label` 用 `阶段N：小标题` 格式（例：`阶段三：钱包、女厕与金发死对头`），`role = "act"`；情绪最高的那个节点 `role = "climax"`。
- 最后一个节点固定以 `收尾：` 开头，`role = "outro"`。
- 总共 5–8 个节点。

### 每个节点的 clips

- 2–5 个 `clip`。
- **每个节点至少有一个 clip 落在上面高能点清单的 `gap` 区间里。**
- `clip.start` / `clip.end` 是正片秒数，必须落在 `0` 到 `{{duration_readable}}` 之内，且不要落在片头曲/片尾曲区间。
- 一个节点的多个 clip 可以来自全集任意时间点——允许把 00:01 的画面和 00:18 的画面拼在同一段旁白下。
- `clip.visual` 写这个片段的画面特征，给剪辑的人看，用 `A ➔ B ➔ C` 描述镜头推进（例：`伊月被扑倒 ➔ 大小姐居高临下 ➔ 特写手腕`）。不要写「主角说话」这种没信息量的描述。
- `clip.anchor_lines` 填这个片段对应的对白轨行号；如果该片段落在无台词间隙里，填紧邻前后的行号。

### 旁白文案

- 口语，短句，有态度。可以吐槽，可以下判断。
- **禁止复述字幕原文**。台词该让原声自己说，你的活儿是补上字幕说不出来的东西：画面在干什么、人物为什么这么反应、这一段在整集里意味着什么。
- **禁止剧透本集之后的剧情，禁止提前说穿结局。**
- 全部节点旁白字数合计约 `{{target_seconds}} × 4.5` 字。

### 留白（holds）

原声金句该让位就让位。全集给 3–6 处 `hold`：

- `hold.at` 是相对**本节点旁白起点**的秒数。
- `hold.duration` 是留白时长，一般 2–4 秒。
- `hold.quote` 填要留给原声的那句台词原文。
- 留白时长会计入总时长预算，所以写旁白时给它留出位置。

### 音频与音效

- `audio.original_audio` 默认 `duck`（原声压低垫底）。留白密集的节点也用 `duck`。只有需要旁白完全独占时才用 `mute`，需要原声全开时用 `full`。
- `audio.sfx` 可选，`cue` 从 `impact` / `whoosh` / `comedy` / `suspense` / `uplift` 里选，`at` 是相对本节点旁白起点的秒数。别滥用，一个节点最多 2 个。
