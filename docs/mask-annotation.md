# 遮罩标注（人工审核后的整屏模糊）

内容检查（`tenmin check-content` / `tenmin run --only check`）会抽帧、评分、把可疑画面列进报告页。
人工看完之后，如果确认某些片段确实有问题、不能直接发布，就用这套流程把它们**整屏高斯模糊**掉，
然后重渲染成片。

模糊是**加一层高斯模糊**，不是黑屏、不打码方块：画面轮廓和颜色还在，但看不出具体内容。
tenmin 自己烧的解说字幕**保持清晰**——模糊只作用在番剧画面上。

## 整体流程

```
check 阶段出报告
  → 08_check/E02/report.html        （浏览器打开）
  → 人工点「标记需遮罩」或用「手动添加区间」填时间、调 sigma
  → 点「导出 mask.json」            （浏览器下载到本地）
  → tenmin mask saijo --episode 2 --import ~/Downloads/mask.json
  → 08_check/E02.mask.json          （标注落到项目里）
  → tenmin run saijo --episode 2 --only render
  → 07_render/E02.mp4               （重渲染，那几秒是模糊的）
```

## 一、在报告页上标记

打开 `work/<slug>/08_check/E02/report.html`（管线跑过 check 阶段后就有）。

- 每张候选卡片右下角有「**标记需遮罩**」按钮，点一下就把这一帧加进遮罩区间，
  默认覆盖 `[该帧时间, 该帧时间 + 2 秒]`。再点一次取消。
- 页面顶部「**遮罩标注**」面板里可以：
  - 改每个区间的起止时间（步进 0.1 秒）；
  - 删掉不想要的区间；
  - 调**模糊强度 sigma**（默认 20，步进 0.1）。
- 标注存在浏览器的 localStorage 里，刷新页面不会丢。

### 加自己发现的时间点

模型没标为候选、但你自己看片发现有问题的时间点，用「**手动添加区间**」那一行加进来：

- 起点、终点都可以写**秒数**（`186.2`），也可以写 **`mm:ss`**（`03:06.2`）或
  **`hh:mm:ss`**（`00:03:06.2`）格式。
- 填完点「添加区间」（或直接回车）。起止填反了会被拒掉并提示「终点必须晚于起点。」。
- 加进来的区间和「标记需遮罩」的区间混在一起，一起导出。

已经加进去的区间也能改：在上面的区间列表里直接改起止时间。改反了会被**还原并提示**，
不会把非法区间带进导出文件（`tenmin mask --import` 那边的 `end > start` 校验会拒掉它）。

**区间用的是成片时间轴**（成片从 0 秒开始算），和报告里每张卡片显示的时间戳是同一根轴。
所以「报告里标哪一帧，模糊就作用在成片的同一时刻」，不用换算。

sigma 的实测档位（1920×1080）：

| sigma | 效果 |
| ----- | ---- |
| 16    | 还能看出轮廓，勉强认得清 |
| 20    | 默认，糊成一片基本认不出（推荐） |
| 24    | 完全糊掉，画面信息全无 |

## 二、导出并导入

报告页上点「**导出 mask.json**」，浏览器会下载一个文件（内容形如）：

```json
{
  "schema_version": 1,
  "episode": 2,
  "sigma": 20,
  "ranges": [
    { "start": 156.0, "end": 162.5 }
  ]
}
```

如果浏览器拦了下载，页面会把同样的 JSON 显示在面板下方的灰框里，手动复制保存成 `mask.json` 即可。

然后导入到项目：

```bash
tenmin mask saijo --episode 2 --import ~/Downloads/mask.json
```

导入会打印段数、总时长、sigma，并提示下一步命令。

标注文件落在 `work/<slug>/08_check/E02.mask.json`（**是 `08_check/E02/` 的兄弟文件**，
不在那个目录里面——那个目录归内容检查的工具所有，塞别的文件进去会让它拒绝再写）。

## 三、重新渲染

```bash
tenmin run saijo --episode 2 --only render
```

render 阶段会读 `08_check/E02.mask.json`，在成片时间轴的对应区间上加高斯模糊，
然后**重新烧解说字幕**——所以字幕始终清晰。

标注文件是 render 阶段的输入：改了标注再跑 `--only render` 会重渲染；
标注文件不存在时渲染结果和以前**逐字节一样**，老项目不受影响。

## 四、查看与删除

```bash
tenmin mask saijo --episode 2          # 看当前标注（段数、每段起止、sigma）
tenmin mask saijo --episode 2 --clear  # 删掉标注
```

删完标注后，下一次 `--only render` 会重新出一版不模糊的成片。

## 独立使用（`tenmin mask-apply`）

上面那条链是「给 tenmin 的成片打码」。如果要给**任意一个视频**打码（不是 tenmin 出的成片），
用独立命令，它不经过 tenmin 的管线，也不要求视频在某个项目里登记过。

```bash
# 1) 检查（完全独立于 tenmin 项目，只要一个视频路径）
tenmin check-content 任意视频.mp4

# 2) 打开报告（默认在视频旁边的 任意视频.content-check/report.html）
open 任意视频.content-check/report.html

# 3) 在报告页上标记 → 导出 mask.json

# 4) 打码
tenmin mask-apply 任意视频.mp4 --mask ~/Downloads/mask.json
```

输出默认落在视频旁边的 `任意视频.masked.mp4`；`--out` 可以指定别的路径，
**输出已存在必须加 `--force`**（防止手滑把原片盖掉）。

| 选项 | 作用 |
| ---- | ---- |
| `--mask <文件>` | 标注文件（必需） |
| `--out <路径>` | 输出路径，默认 `<原名>.masked.<扩展名>` |
| `--sigma <值>` | 覆盖标注文件里记的模糊强度 |
| `--encoder` / `--crf` / `--preset` | 编码器与质量，默认 libx264 / 20 / medium |
| `--force` | 允许覆盖已存在的输出 |

**时间轴是这个视频自己的时间轴**（不是成片时间轴），所以报告里标第几秒就糊第几秒。
如果标注文件里带着 `episode` 字段（那通常是成片时间轴），命令会**打印一条黄色警告**提醒你对不上。

视频轨和音轨原样保留（音频直接 copy、不重编码），分辨率、时长、帧率不变；
字幕轨**不搬运**（硬字幕在画面里，跟着一起糊；软字幕轨在这个命令里不处理）。

## 注意事项

- **一个集一份标注**：标注里带集号，导 E02 的标注拿去导 E12 会被拒绝。
- **标注不记录视频身份**：遮罩后成片必然重渲染、mtime 必变，带身份会把标注自己判为失效。
- **重跑 check 会重新抽帧**：改完标注重渲染后如果再跑 check，缓存身份变了会重新推理一次。
- **区间会被合并**：重叠或首尾相接的区间在导入时自动合并成一个，不会重复遮。
- **独立命令只带一条视频轨和第一条音轨**：源片里的封面图轨、字幕轨不会被复制过去。
- **不想开报告页也能加**：直接编辑项目里的 `work/<slug>/08_check/E02.mask.json` 加一段，然后 `tenmin run <slug> --episode N --only render` 就行（标注文件是 render 的输入，改完会自动重渲染）。
