# OCR 第二轮语义复核

用户已确认：现有 `--ai-correct` / `ocr.ai_correct: true` 自动执行两轮。

第一轮保留现有错字校对。第二轮读取原稿、第一轮结果和前后对话，检查所有条目，包含第一轮误改及仍然不通顺的句子。允许在上下文明确信息时修复整句表达；不得添加剧情、改变人物关系、金额、否定或翻译语言。不确定条目保留第一轮实际采用的文本，并记录候选修正和理由。

第二轮仍按 60 条分批，边界各附两条只读上下文；时间与数量由程序保留，编号严格对齐。一批失败则整轮作废，交付完整第一轮结果，警告并标记待重试；普通运行重新执行两轮，不重新 OCR。第一轮失败仍交付 OCR 原稿。

共享选择入口覆盖独立 OCR 与项目管线。缓存身份加入第二轮提示词摘要；人工编辑保护沿用既有规则。第一轮直接调用接口保持不变。
