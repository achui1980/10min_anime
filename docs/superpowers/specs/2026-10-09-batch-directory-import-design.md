# 批量目录导入与 OP/ED 区间预览设计

日期：2026-10-09
状态：设计已获用户确认（含第二轮修订），等待用户审阅 spec

## 背景与目标

当前 `tenmin run <slug>` 能批量处理已登记集；单集登记则需要逐集运行命令并显式提供集数、字幕和视频。用户通常把同一季的视频与同名 SRT 放在一个目录中，还要手动找 OP 起始位置并写入 `project.yaml`。本设计增加一次扫描、预览、确认的批量入口，减少逐集拼命令和手改配置。

目标：

1. 扫描用户指定目录中的视频及配对 `.srt`，从文件名提取集数。
2. 对可导入集复用现有字幕清洗与 credits 推断逻辑，预览完整 OP 与 ED 区间。
3. 在任何配置变更前向用户展示配对、推断区间和异常项，并要求明确确认。
4. 确认后登记可导入集、写入可用的区间建议，再对本次导入的集运行管线。

## 核心约束：为什么 OP 和 ED 必须一起写

这是本次设计最容易踩错的地方，所有相关决策都由它推导。

`op_range` / `ed_range` 不只是「记录区间」，它还**直接驱动 credits 识别窗**（`ingest/credits.py` 的 `in_credit_window`）：

- 两个字段都空 → **盲窗模式**：片头 `credit_head_window`（300 秒）+ 片尾 `ed_keyword_window_seconds`（80 秒），`is_credits` 的规则 2b/4/5 在整个盲窗里开火。
- 任一字段非空 → **手填模式**：窗变成「区间 ± `manual_window_margin`（5 秒）」，盲窗完全不参与；**且只填一半时另一半彻底关闭、不回退盲窗**。

由此得到两条硬约束：

1. 只写 `op_range` 不写 `ed_range`，会把片尾窗从「最后 80 秒」变成**不存在** → ED staff 行不再判成 `credits` → 靠 credits 聚簇的 ED 推断也随之失效。结果是「OP 填好了、ED 彻底丢了」。
2. 即便两个都写，窗也会从盲窗收窄成区间 ± 5 秒。因此**写入动作本身会改变下一次 ingest 的产出**，不再等于预览所依据的那次推断。这是把推断值固化成手填值的固有代价，设计上接受它，但要求两个区间同时存在、避免出现只有一半窗的畸形状态。

**决策：OP 与 ED 都推断；只有两个都成功推断出来时才写入 yaml；任一推不出来就两个都不写**，让那一集保持现有盲窗行为，由 ingest 自己推断（预览仍然把结果展示给用户）。

## 已确认的设计决策

1. 新增独立命令 `tenmin import <slug> <directory>`，不把目录扫描职责塞进已有 `tenmin run`。`import` 是 Python 关键字，实现上用 `@app.command("import")` 显式指定命令名、函数命名为 `import_`。
2. 扫描指定目录第一层，不递归；视频后缀复用 `ingest.ocr_batch.VIDEO_SUFFIXES`（`.mp4`、`.mkv`、`.mov`、`.m4v`、`.webm`、`.avi`、`.ts`，大小写不敏感）。
3. 视频与字幕配对（大小写不敏感，字幕扩展名为 `.srt`）：
   - 文件名主体完全相等；或
   - 文件名主体 + 分隔符（`.` 或 `_`）+ 一个语言后缀（`zh-Hans`、`zh-Hant`、`sc`、`tc`、`chs`、`cht`、`zh`、`ja`、`jp`、`jpn`）。
   语言后缀必须放开，因为 `tenmin ocr` 自己的产物就是 `<stem>.zh-Hans.srt` / `<stem>.zh-Hant.srt`，下载字幕也普遍带这类后缀。同一视频命中多个候选 SRT 时按上述列表顺序取第一个，并在预览中显示被选中与被忽略的文件。不做模糊匹配。
4. 新增 `--srt-dir <path>`：字幕不在视频目录时从该目录配对。省略时等于视频目录。这是为了衔接 `tenmin ocr -o <dir>` 把 SRT 写到独立目录的既有流程。
5. 集数识别**正则优先、LLM 兜底**：
   - 第一级强模式：`E01`、`EP01`、`S01E01`、`第01集`、`第01話`（含半角/全角数字）。
   - 第二级弱模式（强模式全部未命中时）：被分隔符（`-`、空格、`[`、`]`、`.`、`_`）包围的 1–3 位数字，且先剔除已知噪声 token（`1080P`、`720P`、`2160P`、`4K`、`x264`、`x265`、`H264`、`H265`、`AVC`、`HEVC`、`8bit`、`10bit`、`AAC`、`FLAC`、`OPUS`、四位年份）。
   - 第三级 LLM 兜底：第二级仍无命中或判为歧义（同一文件名剩下多个候选数字）的文件名，**打包成一次调用**交给 LLM，由它为每个文件名输出集号或「非正片」标记。
   - LLM provider 只在确实需要兜底时才构造（复用 `script.llm.build_provider(cfg.llm, settings)`）。构造失败（如缺 API key）不中断命令：那些歧义文件按「跳过并列出」处理，正则已判定的集照常导入。
6. 非正片素材（NCOP、NCED、SP、OVA、PV、预告、Menu）由噪声/关键词规则排除，LLM 兜底也可显式标记为「非正片」，一律跳过并在预览中列出。
7. 仅导入成功配对的视频与 SRT。未配对视频/字幕在预览中列出并跳过；本功能不处理无字幕视频入口。
8. 区间推断复用现有路径（`normalize.build_track` → `credits.find_credit_ranges`），依据字幕 staff 行及片头静音段，不新增音频或画面识别算法。展示 OP 与 ED 的完整起止；推断不可用时显示「未识别」。
9. 写入规则（由上一节推导）：
   - 只对 `op_range` 与 `ed_range` **都为空**的可导入集写入；任一已有手填值时一个都不写，避免制造混合状态。
   - 两个区间都推断成功才写；任一失败则都不写，仅提示。
   - 写入前把秒数四舍五入到 0.1 秒，避免 yaml 里出现 `30.471428` 这种值。取整后若出现 `start >= end` 则视为推断失败、不写入。
10. 已完整登记（已有 srt 或 video）的集默认跳过，保护已有输入与人工配置。只有预填条目（无 srt 也无 video）可以补齐来源，且保留其已有 `op_range` / `ed_range`。
11. 交互与副作用：
    - 默认打印预览并等待确认；拒绝/取消时不写文件、不改 `project.yaml`、不运行管线。
    - `--yes` 跳过确认（CI、脚本、测试用）。
    - `--dry-run` 只预览，不写不跑。扫描、集数解析（含 LLM 兜底）、ffprobe 探测与区间推断照常执行 —— 它们都是只读操作，预览要完整才有意义。
    - 非 TTY 且未传 `--yes` 时报错退出，不静默执行。
12. 确认后**只对本次导入的集**运行管线（逐集走 `run_pipeline` 单集模式），不触发全量批处理 —— 否则 `zh/glossary.json` 等项目级输入一变动就会连带重跑存量集。

## 命令及交互

```bash
uv run tenmin import saijo "/path/to/season"
uv run tenmin import saijo "/path/to/video" --srt-dir "/path/to/srt" --dry-run
uv run tenmin import saijo "/path/to/season" --yes
```

流程：

1. 加载 `work/<slug>/project.yaml`；校验目录（及 `--srt-dir`）存在且为目录。
2. 单层枚举视频与 SRT，按主体 / 主体+语言后缀建立配对。
3. 正则提取集数；剩余歧义项打包交 LLM 兜底（必要时才构造 provider）。
4. 检查项目登记状态与集号冲突，分出「可导入 / 已登记跳过 / 歧义跳过 / 未配对跳过」四类。
5. 对可导入集做区间推断：用 ffprobe 取真实片长，调 `build_track` 得到 `op_range` / `ed_range`。
6. 输出逐项预览：集数、视频、SRT、OP 区间、ED 区间（或未识别）、是否写入区间、跳过原因；另列未配对文件、歧义文件、非正片文件。对会导致存量产物失效重跑的集（见下节）给出提示。
7. 请求确认（受 `--yes` / `--dry-run` / 非 TTY 规则约束）。未确认即结束且无副作用。
8. 对确认项登记视频绝对路径、拷贝 SRT 至 `srt/E{NN}.srt`，按第 9 条写入区间建议。
9. 逐集运行管线。已有产物按现有新鲜度规则跳过。保留现有 CLI 对错误、warning 和产物路径的报告约定。

没有任何可导入项时，展示扫描结果并正常结束，不请求确认、不运行管线。

## 模块边界与数据流

- CLI 层（`src/tenmin/cli.py`）：新增 Typer `import` 命令（函数名 `import_`），负责加载项目、调用扫描/预览、处理确认开关，然后触发管线。
- 目录导入模块（`src/tenmin/importer.py`）：文件枚举、配对、集数解析（含 LLM 兜底调用）、冲突分类、区间预览候选。不负责启动流水线。
- 集数解析子单元：纯函数 `parse_episode_number(stem) -> int | None | Ambiguous`，与 LLM 兜底 `resolve_ambiguous(stems, provider)` 分离，前者可完全离线测试。
- Pipeline/config 层：扩展 `register_episode`，在登记时支持「仅当 `op_range` 与 `ed_range` 都为空时写入这两个值」。沿用其 SRT 原子拷贝与 ruamel round-trip 写回，绝不覆盖用户已有的 OP/ED 配置、注释和键序。
- 区间推断：复用 `normalize.build_track` 与 `credits.find_credit_ranges`，使预览与 ingest 采用同一套分类和区间规则。预览本身不写 ingest 产物。
- 管线：调用现有 `run_pipeline` 单集模式，不复制阶段编排。

## 片长口径

`find_credit_ranges(lines, duration, ...)` 的 duration 是必需参数，ED 窗按它计算。`build_track` 在 `duration=None` 时会**静默降级**成字幕最后一条 cue 的结束时间（`normalize.py:207-208`），而字幕末尾通常早于真实片长（ED 之后还有画面），会让 ED 区间算偏。

所以预览必须拿真实片长：

- 优先用 ffprobe 探测，沿用现有 `_source_duration` 的语义（`FFmpegBinaryError` 照旧往外抛，其余 `FFmpegError` / `OSError` / 文件不存在降级为 None）。
- 片长拿不到时，预览显式标注「片长未知」，并按第 9 条**不写入任何区间**（ED 口径不可信）。该集仍然登记并继续。

## 冲突和错误处理

- 输入路径或 `--srt-dir` 不存在/不是目录：单行中文错误，非零退出。
- 项目配置读取/校验失败：复用现有用户可读错误处理。
- 视频无配对字幕、字幕无配对视频：预览列出并跳过。
- 集号缺失、歧义（含 LLM 兜底后仍无法确定）、重复集号：列出并跳过冲突项；不得以排序顺序补集号。
- LLM 兜底不可用（缺 key、调用失败）：警告，受影响文件按歧义跳过，不影响其他集。
- 已登记且有 source 的集：标记为已有集并跳过，既不替换来源也不覆盖区间。
- 项目预填但无来源的集：可补齐来源；保留已有手填区间，两个都空时才写入推断建议。
- **写入区间会让该集的 EPISODE 配置切片变化**（`config_slices.py` 的 EPISODE 切片含 `op_range` / `ed_range`），导致该集已有的 ingest / timeline / audio / render 产物失效重跑。新集无影响，补齐来源的预填集要在预览中提示。
- 区间推断没有结果或片长未知：提示，仍登记这一集并继续批次。
- 非 TTY 且未传 `--yes`：报错退出，不静默执行。
- 用户拒绝确认 / `--dry-run`：零副作用正常退出。
- 运行时登记或流水线错误：沿用现有 CLI 的错误格式和非零退出；已落盘内容按现有原子写入语义保留，不做跨文件事务回滚。

## 测试设计

使用临时目录、可控 SRT 样本与 fake LLM provider 覆盖：

- 扫描只看第一层；视频与 SRT 扩展名大小写不敏感。
- 配对：主体完全相等；主体 + 各语言后缀；多候选时按优先级取一个并提示；`--srt-dir` 从独立目录配对。
- 集数正则：强模式各形式；弱模式在真实命名（如 `[ANi] xxx - 11 [1080P][AVC AAC][CHT].mp4`）下正确取 `11` 而非 `1080`；噪声 token 被剔除。
- LLM 兜底：仅在正则失败时被调用（正则全命中时 provider 完全不构造）；fake provider 返回集号 / 「非正片」标记 / 调用失败三种分支。
- 非正片素材（NCOP/SP/PV）被跳过并列出。
- 区间推断预览与 `build_track` 在同一字幕/配置下结果一致；未识别时显示未识别。
- **写入规则**：OP+ED 都推断成功才写；只有一个成功时两个都不写；已有任一手填值时一个都不写；写入值取整到 0.1 秒。
- 片长未知时不写区间但仍登记。
- 已登记集跳过；预填集被补齐且已有区间保留。
- 交互：默认需确认；`--yes` 跳过确认并执行；`--dry-run` 零副作用；非 TTY 无 `--yes` 报错退出。
- 确认后只对本次导入的集调用管线，不触发全量批处理。
- 登记保留 YAML 注释、键序与其他字段。
- 错误项目/目录产生可读错误；异常集不阻塞有效且无冲突的集。

## 范围之外

- 依据音乐、画面转场、片头曲指纹或机器学习模型识别 OP/ED；当前设计只复用字幕侧推断。
- 给 ingest 新增「自动推断值不收窄识别窗」的标记位（会改动 credits 三级回退语义，本次不动）。
- 无字幕视频登记 / ASR / OCR 工作流；当前批量导入要求配对 SRT。
- 递归扫描、模糊配对、自动按排序补集数、手动逐文件映射。
- 自动覆盖已有完整登记集或人工填写的 `op_range` / `ed_range`。
- 修改现有 `tenmin run` 单集或批处理语义。
- 按集覆盖 `render` 等项目级配置。
